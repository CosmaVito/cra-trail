# Security policy for CVD Inbox

CVD Inbox is the example application of cra-trail. It is not meant for production use. Reports about it are still welcome.

## Reporting a vulnerability

Report it privately through GitHub: https://github.com/CosmaVito/cra-trail/security/advisories/new. Include the version, the steps to reproduce and the impact you observed.

I acknowledge reports within 5 working days and keep you informed until the issue is fixed. Please do not disclose the issue publicly before a fix is available or 90 days have passed, whichever comes first.

## Supported versions

| Version | Supported until |
|---|---|
| 0.1.x | 2027-12-31 |

## Security updates

Fixes ship as new cra-trail releases, with a new demo zip and container image, and are announced in the release notes and in the repository security advisories.
